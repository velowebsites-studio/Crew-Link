CrewLink needs a Firebase project to sync live locations, chat, pins and routes between racers.

  1. Create a project at firebase.google.com
  2. Enable Email/Password sign-in under Authentication
  3. Create a Firestore database
  4. Copy your web app config into firebaseConfig near the bottom of index.html
  5. Deploy the rules in firestore.rules
